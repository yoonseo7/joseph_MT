# 요셉 리더 MT 웹 테스트

**2026 하반기 요셉 리더 MT · 만청 요셉 공동체**

리더들이 약 1분간 5개의 질문에 답하면 오후 활동 팀(A 화담숲 산책 / B 연못 옆 카페 / C 곤지암 루지360)을 추천받고, 이름이 들어간 결과 카드 이미지를 저장하는 웹 테스트입니다.

---

## 파일 안내

| 파일 | 역할 | 수정 빈도 |
|---|---|---|
| **content.js** | **모든 문구 · 질문 · 결과 · 후보안** | ⭐ 여기만 고치시면 됩니다 |
| index.html | 페이지 뼈대 | 거의 안 고침 |
| style.css | 색 · 글꼴 · 배치 | 디자인 바꿀 때 |
| illust.js | 팀별 일러스트(SVG) | 그림 바꿀 때 |
| app.js | 화면 전환 · 채점 · 카드 이미지 생성 | 기능 바꿀 때 |
| **SETUP.md** | **응답 수집 + 배포 방법** | ⭐ 배포할 때 읽기 |
| .nojekyll | GitHub Pages 정상 게시용 | 건드리지 않기 |
| _backup/ | 이전 버전 백업 | 참고용 |

## 문구 고치는 법

`content.js` 하나만 열면 됩니다. 파일 맨 위에 사용법이 적혀 있습니다.

여러 후보 중 하나를 고르는 항목은 이렇게 생겼습니다.

```javascript
   name: '천천히 누리는 리더',
// name: '숲멍 말고 숲걷기파',
```

쓰고 싶은 줄의 `//` 를 지우고, 안 쓸 줄 앞에 `//` 를 붙이면 됩니다.
저장하고 브라우저 새로고침(F5)하면 바로 반영됩니다.

> **수정했는데 화면이 그대로라면?**
> 브라우저가 옛날 파일을 기억(캐시)하고 있는 겁니다.
>
> 1. 먼저 **Ctrl+Shift+R** (강력 새로고침)을 눌러보세요. 대부분 이걸로 해결됩니다.
> 2. 그래도 안 되면 `index.html` 을 열어 아래 네 줄의 **`?v=11` 숫자를 8, 9…로 하나 올리고** 저장하세요.
>    브라우저가 새 파일로 인식해서 무조건 다시 불러옵니다.
>
> ```html
> <link rel="stylesheet" href="style.css?v=11">
> <script src="content.js?v=11"></script>
> <script src="illust.js?v=11"></script>
> <script src="app.js?v=11"></script>
> ```

**후보가 준비된 항목**
- 큰 제목 5개
- 팀별 유형 이름 / 대표 대사 / 설명 각 2개씩
- 미사용 질문 후보 전체 (파일 맨 아래 `[부록]`)

## 로컬에서 보기

이 폴더에서 터미널을 열고:

```powershell
py -m http.server 5500 --bind 127.0.0.1
```

브라우저에서 `http://localhost:5500` 접속. 종료는 Ctrl+C.

> 파일을 더블클릭해서 열면(`file://`) 일부 기능이 막힙니다. 반드시 위 방법으로 여세요.

## 배포 · 응답 수집

**`SETUP.md`** 에 순서대로 정리해 두었습니다.

1. Google Apps Script + 비공개 구글 시트로 응답 수집 (무료, 약 10분)
2. GitHub Pages 웹 업로드로 배포 (약 5분)
3. 행사 후 정리 (개인정보 삭제)

응답 수집을 연결하기 전까지는 이름 화면에 "체험 버전" 안내가 표시되고 아무 데도 전송되지 않습니다.

## 디자인 메모

흰 배경 · 밝고 상큼한 색 · 가벼운 느낌으로 잡았습니다.

| 용도 | HEX |
|---|---|
| 배경 | `#FFFFFF` (순백) |
| 옅은 블록 | `#F7F9F8` |
| 본문 글자 | `#1A1D1B` |
| A · 화담숲 | `#16B364` (민트그린) |
| B · 연못 카페 | `#2E90FA` (스카이블루) |
| C · 루지 | `#FF5A3C` (코랄) |

글꼴은 Noto Sans KR 하나만 씁니다. 버튼은 알약 모양(pill), 카드는 둥근 모서리로 가볍게 처리했습니다.
팀별 일러스트는 이미지 파일이 아니라 `illust.js` 안에 SVG로 그려져 있어, 팀 색이 자동으로 적용되고 확대해도 깨지지 않습니다.

## 참고

- 결과는 **추천**이며 인원 균등 배정이 아닙니다. 실제 배정은 시트를 보고 운영자가 조정합니다.
- 결과 카드 PNG는 화면과 별도로 그려집니다. `style.css`를 바꿔도 이미지에 자동 반영되지 않고, `app.js`의 `card()` 함수를 함께 고쳐야 합니다.
- 질문 개수는 자유입니다. `content.js`의 `QUESTIONS`에서 넣고 빼면 진행 막대와 번호가 자동으로 맞춰집니다.
